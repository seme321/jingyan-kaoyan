# 试卷与新专业课板块导入说明书（供 AI 使用）

> **用途说明**：当你（拥有本仓库读写与终端权限的 AI 助手）拿到已生成的标准真题数据包（`<year>.json` + `figures/`），或需要为网站新增一门考研专业课板块时，请按本说明书执行自动化入库、校验与构建。

---

## 一、核心目录拓扑速览

```text
水力学/
├── docs/                                    # AI 生成与导入标准说明书
├── scripts/
│   ├── ingest_exam.py                       # 【主力工具】标准真题数据包一键转换 WebP + 入库脚本
│   ├── validate_course.mjs                  # 【必跑门禁】Schema + 分值 + 采分点 + 真 KaTeX 零错校验器
│   └── init_courses.py                      # 多板块目录初始化参考脚本
└── web/
    ├── public/data/
    │   ├── courses.json                     # 全站考研专业课板块总目录（控制顶部板块切换器）
    │   ├── hhu-814/                         # 板块 1：河海大学 · 814 水力学
    │   │   ├── index.json                   # 本板块年份清单（status: "ready" | "planned"）
    │   │   ├── chapters.json                # 本板块章节考纲与命题特征
    │   │   ├── formulas.json                # 本板块核心公式闪卡库
    │   │   ├── 2026.json / 2025.json / ...  # 各年真题数据
    │   │   └── figures/<year>/*.webp        # 自动生成的压缩 WebP 配图
    │   └── yzu-849/                         # 板块 2：扬州大学 · 849 水力学（水）
    │       ├── index.json
    │       ├── chapters.json
    │       ├── formulas.json
    │       └── figures/
    └── src/                                 # React + TypeScript + KaTeX 多板块通用前端（导入新卷无需改代码！）
```

## 二、场景 A：向已有板块导入一套新试卷（最常用，1 条命令搞定）

假设你已按《01_真题精解数据包生成说明书》在 `扬州大学已整理数据/2024/` 下生成了 `2024.json` 和 `figures/` 图片目录，要将其导入扬大 849 板块（`courseId = yzu-849`）：

### 执行命令
在项目根目录运行：

```powershell
python scripts/ingest_exam.py --course yzu-849 --json "扬州大学已整理数据/2024/2024.json" --figures "扬州大学已整理数据/2024/figures"
```

### 该脚本会自动完成以下全部工作：
1. **ID 命名空间保护**：自动将题目 `id` 规范化为 `yzu-849-2024-01` 格式，防止跨板块 `localStorage` 冲突；
2. **常见 LaTeX 瑕疵自愈**：自动修复 `^{'}`、`^{''}`、`^{^{\circ}}` 等常见双上标问题；
3. **配图转码归档**：自动将 `--figures` 下的 PNG/JPG 图片转为高清晰度 `.webp` 存入 `web/public/data/yzu-849/figures/2024/`，并重写 JSON 内的图片相对路径；
4. **激活索引与板块状态**：自动更新 `web/public/data/yzu-849/index.json`（将该年份设为 `"status": "ready"` 并按年份倒序排列），同时自动将 `courses.json` 中 `yzu-849` 的状态激活为 `"ready"`；
5. **触发全量硬核校验**：自动调用 `node scripts/validate_course.mjs --course yzu-849`。

### 若校验报错如何处理？
`validate_course.mjs` 会精确打印出有问题的题号与原因（例如 `[ERROR] yzu-849-2024-06: rubric sum 14 != question score 15` 或 `KaTeX error in "..."`）。
- 请直接修改源 JSON 文件修复对应字段，然后重新运行上述 `python scripts/ingest_exam.py ...` 命令，**直到控制台输出 `Total errors: 0` 为止**！

## 三、场景 B：新增一门全新的考研专业课板块（例如土力学 / 结构力学 / 其他院校）

无需修改任何前端 `.tsx` 代码，只需在 `web/public/data/` 下完成以下 4 个 JSON 配置：

### 第 1 步：确定唯一的 `courseId`
命名规范：`<学校拼音缩写>-<科目代码>`（全小写英文+连字符），例如：
- 河海大学 814 水力学：`hhu-814`
- 扬州大学 849 水力学：`yzu-849`
- 河海大学 813 材料力学：`hhu-813`
- 东南大学 925 结构力学：`seu-925`

### 第 2 步：在 `web/public/data/courses.json` 注册板块
向 `courses` 数组追加一项：
```json
{
  "id": "hhu-813",
  "name": "河海大学 · 813 材料力学",
  "shortLabel": "河海 813",
  "school": "河海大学",
  "code": "813",
  "subject": "材料力学",
  "category": "土木 / 水利 / 力学考研专业课",
  "examMetaBadge": "科目代码 813 · 满分 150 分 · 闭卷",
  "status": "preparing",
  "description": "一句话简介该科目的真题收录情况与特色考点。"
}
```
> 添加后，网站顶部左上角的「板块切换器」和移动端抽屉就会立即出现该板块！

### 第 3 步：创建 `web/public/data/<courseId>/` 基础三件套
创建文件夹 `web/public/data/<courseId>/` 并放入以下 3 个 UTF-8 JSON 文件（格式可参考 `web/public/data/yzu-849/` 下的同名文件）：

1. **`chapters.json`**：定义本专业课的章节目录、题型规律、分值区间（如 `"15-25"`）、星级难度（`1..3`）、是否常出大题（`hasBigQuestion`）及核心考点词条（`coreKps`）。
2. **`formulas.json`**：整理本专业课 20～50 组核心必背公式（含 `id`、`chapter`、`name`、`latex`、`variables`、`note`）。注意每条公式的 `chapter` 必须在 `chapters.json` 中存在！
3. **`index.json`**：初始可设为 `{"availableYears": []}`，或填入待导入的年份占位（`"status": "planned"`）。

### 第 4 步：执行门禁校验与前端构建验证
每次新增板块或导入新试卷后，**必须**执行以下两条命令做最终验收：

```powershell
# 1. 全站全科目数据完整性与 KaTeX 零错校验
node scripts/validate_course.mjs

# 2. TypeScript 类型检查与生产包构建验证（同步更新离线缓存资源）
Set-Location web; npm run build
```

若开启了离线 PWA 预缓存且希望首屏自动缓存新增的核心 JSON，可同步在 `web/public/sw.js` 中递增 `CACHE_NAME` 版本号。
