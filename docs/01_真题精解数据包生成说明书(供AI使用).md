# 真题精解数据包生成说明书（供 AI 使用）

> **用途说明**：当你（AI 助手）收到用户的原始考研真题资料（PDF 原卷、扫描图片、考生回忆文本或参考答案照片）时，请严格遵循本说明书，输出可直接导入「鲸研专业课」网站的 **标准真题数据包（`<year>.json` + `figures/`）**。
> **核心原则**：**直接输出结构化 JSON + 标准 KaTeX 公式 + 独立图片文件**，不要绕道生成五花八门的 Word `.docx` 再反向解析。

---

## 一、交付物目录结构

每完成一套试卷（例如 `扬州大学 849 水力学` 的 `2024` 年真题），请在对应的「已整理数据」目录下创建以年份命名的文件夹：

```text
<院校已整理数据目录>/

        ├── q01_sol.png        # 第 1 题解析示意图（若有，推荐用 Python matplotlib 绘制）
        ├── q02_orig.png
        └── ...
```

## 二、执行步骤 SOP（AI 必读）

### 第 1 步：核对目标板块的章节体系
生成前，先读取 `web/public/data/<courseId>/chapters.json`（例如扬大 849 为 `web/public/data/yzu-849/chapters.json`，河海 814 为 `web/public/data/hhu-814/chapters.json`），确认合法的章节号 `chapter` 列表（例如 `1..10` 或 `1..11, 13`）。
- **严禁填写 `chapters.json` 中不存在的章节号！**

### 第 2 步：高清提取题干原图 & 绘制解析图
1. **题干配图（`q{题号两位}_orig.png`）**：
   - 若原始资料为 PDF（如 `849-水力学2024（水）.pdf`），请使用 Python（`pymupdf` / `fitz` 或 `pdfium`）以 **300 DPI** 渲染页面并按坐标精准裁切插图（四周保留 `12~20px` 纯白边距，裁掉图号文字如“题 1 图”，因为图号会写在 JSON 的 `caption` 字段里）。
   - 若你拥有重绘能力且图形几何简单（如平行平板、U 形管、矩形渠道），也可直接用 `matplotlib` 绘制高分辨率白底黑线工程示意图（`dpi=220`）。
2. **解析附图（`q{题号两位}_sol.png`，强烈推荐为重点计算/分析题配备）**：
   - 使用 Python `matplotlib` 绘制受力分析图、控制体图、压力体分解图、总水头线/测压管水头线或速度分布图，保存为白底 PNG（中文字体设置 `plt.rcParams['font.sans-serif'] = ['Microsoft YaHei', 'SimHei']`、`plt.rcParams['axes.unicode_minus'] = False`）。
   - 代码自绘的解析图版权 100% 纯净，且清晰度极高。

### 第 3 步：独立验算与编写高质量精解
- **严禁盲目照抄实拍参考答案（如手写照片 `IMG_*.JPG`）！** 必须根据题干给定物理参数独立列方程重算一遍：
  - 若手写答案正确，用更清晰、分步编号（`1. ...` / `（1）...`）的规范工程语言重写推导过程；
  - 若发现参考答案有笔误、漏项或近似误差，以严格物理定律为准，并在 `pitfalls` 字段温和指出易错点（**严禁在任何字段出现“原视频”“B站”“某老师/某机构”“去水印”等第三方字样**）。
- **步骤采分点（`rubric`）设计规则**：
  - 所有分值 `≥ 5 分` 的主观题（`short` 简答分析题、`calc` 计算题、`proof` 推导证明题）**必须配备 `rubric` 数组**（拆分为 2～5 个关键得分步骤）。
  - **硬性校验**：同一道题 `rubric` 各条目的 `pts` 之和 **必须严格等于该题 `score`**！

## 四、KaTeX 公式书写 8 条铁律（违反会导致网页报错）

网站前端使用 **KaTeX**（`throwOnError: true`）渲染公式，语法比普通 LaTeX 更严格：

1. **行内公式与独立公式分隔**：
   - 行内公式用单美元符 `$...$`（**中间严禁换行**）；
   - 独立居中公式块用双美元符，前后空行：
     ```markdown
     $$
     Q = \frac{1}{n} A R^{2/3} i^{1/2}
     $$
     ```
2. **严禁双重上标 `^{'}` 和 `^{^{\circ}}`（头号高频报错！）**：
   - 错误示范：`$h_c^{''}$`、`$R^{'}$`、`$\theta = {30}^{^{\circ}}$`（在 TeX 中 `'` 本身就是上标，放进 `^{...}` 会报 `Double superscript`）。
   - 正确写法：直接写 `$h_c''$` 或 `$h_c^{\prime\prime}$`；`$R'$` 或 `$R^{\prime}$`；角度统一写 `$30^{\circ}$`。
3. **中文文字进入公式必须包 `\text{...}`**：
   - 正确写法：`$z_{\text{上}} = 115\,\mathrm{m}$`、`$\eta_{\text{泵}} = 70\%$`。
4. **百分号 `%` 在 `$...$` 内必须转义为 `\%`**：
   - 错误示范：`$\eta = 70%$`（`%` 在 TeX 中是注释符，会把后面的 `$` 注释掉导致整段崩溃！）。
   - 正确写法：`$\eta = 70\%$`。
5. **物理单位建议正体 `\mathrm{...}` 并加窄空格 `\,`**：
   - 示例：`$Q = 0.20\,\mathrm{m^3/s}$`、`$\mu = 0.0585\,\mathrm{Pa\cdot s}$`。
6. **`\left` 与 `\right` 必须同一行严格成对**：
   - 单侧竖线（代入上下限）必须补齐空定界符 `\left.`：如 `$\left. \frac{\mathrm{d}u}{\mathrm{d}y} \right|_{y=0}$`。
7. **填空题下划线占位符**：
   - 题干中的填空横线统一用 8 个英文下划线 `________`（不要放进 `$...$` 里），前端会自动渲染为美观的下划线槽。
8. **正文普通美元符号**：若题干出现非数学含义的美元符号，需写为 `\$`，防止误触发行内公式。

## 五、交付前自检清单

在宣布某套试卷数据包生成完毕前，请逐项核查：
- [ ] `questions` 数组题号 `no` 是否从 `1` 连续排到最后一题，且与 `sections[].range` 完全闭合无遗漏？
- [ ] 所有题目 `score` 之和是否等于 `totalScore`（如 150 分）？
- [ ] 每道大题 `rubric` 的 `pts` 之和是否等于该题 `score`？
- [ ] 每道题的 `chapter` 是否都在目标板块 `chapters.json` 定义的章节编号内？
- [ ] `figures` 和 `analysisFigures` 引用的所有图片文件是否都已真实保存在同级 `figures/` 文件夹下且非空白图？
- [ ] 全文是否不含任何 `视频`、`B站`、`BV1`、`去水印` 等第三方来源痕迹？
