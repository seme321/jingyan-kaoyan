# 鲸研 · 创意工坊资源包制作与导入规范（`.jypack.zip` 统一标准 v1）

> **适用对象**：希望为「鲸研 · 考研专业课智能精解练习系统」制作、分享或安装扩展资源的社区贡献者、AI 辅助整理工具与终端用户。  
> **核心格式**：统一采用以 `.jypack.zip` 结尾的标准 ZIP 压缩包（支持根目录直接存放 `manifest.json`，或包裹一层同名目录）。

---

## 一、资源包类型总览

| `manifest.type` | 中文名称 | 适用场景 | 根目录必备文件 |
| :--- | :--- | :--- | :--- |
| **`course`** | **整科专业课包** | 新增一门独立专业课（例如「河海 813 材料力学」「清华 807 水力学」），自动注册到全站科目切换器 | `manifest.json`、`course.json`、`chapters.json`、`papers/*.json`（可选 `formulas.json`、`figures/*`、`cover.*`） |
| **`exam`** | **单年/多年真题补充包** | 向现有科目（如 `hhu-814`、`yzu-849`）追加新的年份试卷或替换修正特定年份试卷 | `manifest.json`（含 `targetCourseId`）、`papers/*.json`（可选 `formulas.json`、`figures/*`、`cover.*`） |
| **`character`** | **角色干员包** | 新增 SP 看板娘或含 `chibi` / `medium` / `standard` 三阶进化链的干员，支持「即装即用」或「小鱼干卡池抽取」 | `manifest.json`（含 `unlockMode`）、`characters.json`、`assets/*`（可选 `cover.*`） |

> [!TIP]
> **安装后存储位置**：无论是从在线「创意工坊」下载还是「从本地导入 `.jypack.zip`」，浏览器均会自动解析校验并写入本地 **IndexedDB（`jingyan_workshop_v1`）**，刷新或离线断网仍可正常使用，支持随时一键停用、启用或卸载清理。

## 二、通用清单：`manifest.json` 规范

每个 `.jypack.zip` 根目录**必须**存在 `manifest.json`（UTF-8 无 BOM 编码）：

```json
{
  "schemaVersion": 1,
  "packId": "seu-925-mechanics",
  "type": "course",
  "name": "东南大学 · 925 材料力学精解包",
  "version": "1.0.0",
  "author": "整理者署名",
  "license": "仅供个人考研复习与学术交流使用（非商业）",
  "summary": "收录 2020-2024 共 5 年真题精解，含弯曲剪力图与应力分析配图。",
  "description": "可选：更详细的版本更新说明、参考教材或使用提示。",
  "tags": ["东南大学", "925", "材料力学"],
  "cover": "cover.webp",
  "targetCourseId": "hhu-814",
  "unlockMode": "direct"
}
```

### 字段说明与约束

| 字段 | 必填 | 类型 | 说明与校检规则 |
| :--- | :---: | :--- | :--- |
| `schemaVersion` | **是** | `1` | 固定整数 `1` |
| `packId` | **是** | `string` | `3~48` 位小写字母、数字、`-` 或 `_`（正则 `^[a-z0-9][a-z0-9_-]{2,47}$`），全局唯一标识 |
| `type` | **是** | `string` | `"course"` \| `"exam"` \| `"character"` |
| `name` | **是** | `string` | 资源包展示名称（建议不超过 40 字） |
| `version` | **是** | `string` | 语义化版本号（如 `"1.0.0"`）；工坊目录版本变化时会提示用户「可更新」 |
| `author` | **是** | `string` | 制作者或整理者署名 |
| `license` | **是** | `string` | **必填**：版权归属、许可协议及素材来源声明 |
| `summary` | **是** | `string` | 一句话简介（卡片展示） |
| `description` | 否 | `string` | 详细说明（支持换行） |
| `tags` | 否 | `string[]` | 检索标签 |
| `cover` | 否 | `string` | 包内相对路径封面图（如 `"cover.webp"`），推荐比例 1:1、WebP 格式 |
| `targetCourseId` | 视类型 | `string` | **`type: "exam"` 必填**，目标科目 ID（如 `"hhu-814"`、`"yzu-849"`） |
| `unlockMode` | 否 | `string` | **`type: "character"` 适用**：`"direct"`（默认，安装即解锁）或 `"gacha"`（加入小鱼干卡池抽取） |

## 三、专业课与真题试卷包制作规范（`type: "course"` / `"exam"`）

### 1. 目录结构

```text
my-course-pack/
├── manifest.json
├── cover.webp                  # 可选，工坊卡片封面
├── course.json                 # type="course" 必填；type="exam" 无需
├── chapters.json               # type="course" 必填；type="exam" 可省略
├── formulas.json               # 可选，公式卡片集合
├── papers/
│   ├── 2023.json
│   └── 2024.json
└── figures/                    # 所有题目/解析配图（统一相对路径）
    └── 2024/
        ├── q26_orig.webp
        └── q26_sol.webp
```

### 2. `course.json`（仅 `type: "course"` 必填）

```json
{
  "id": "seu-925",
  "name": "东南大学 · 925 材料力学",
  "shortLabel": "东大 925",
  "school": "东南大学",
  "code": "925",
  "subject": "材料力学",
  "category": "水利 / 土木考研专业课",
  "examMetaBadge": "科目代码 925 · 闭卷 · 满分 150",
  "description": "面向 925 材料力学考研真题练习与解析。"
}
```

- `id` 须匹配 `^[a-z0-9][a-z0-9_-]{1,31}$`，且不得与内置科目或其它启用中的学科冲突。

### 3. `chapters.json` 与 `formulas.json`

`chapters.json` 定义章节编号与看板标签（题目 `chapter` 字段必须引用其中存在的 `chapter` 整数）：

```json
{
  "chapters": [
    { "chapter": 1, "name": "绪论与液体主要物理性质", "shortName": "绪论物性", "desc": "黏性、牛顿内摩擦定律、压缩性" }
  ]
}
```

`formulas.json` 可写为 `{"formulas": [...]}` 或直接数组，每条包含：
`id`, `chapter`, `name`, `latex`, `variables`, `conditions`, `note`。

### 4. 单套真题 JSON 规范（`papers/<year>.json`）

```json
{
  "year": 2024,
  "code": "814",
  "subject": "水力学",
  "school": "河海大学",
  "totalScore": 150,
  "durationMinutes": 180,
  "calculatorAllowed": false,
  "examNotes": [
    "满分 150 分，考试时间 180 分钟，闭卷笔试。",
    "除特别说明外，统一取 g = 9.81 m/s²，ρ = 1000 kg/m³。"
  ],
  "sections": [
    { "id": "judge", "title": "一、判断题", "description": "共 10 小题，每题 2 分。", "range": [1, 10], "scorePerQuestion": 2, "totalScore": 20 },
    { "id": "calc", "title": "三、计算题", "description": "共 5 小题，每题 20 分。", "range": [26, 30], "scorePerQuestion": 20, "totalScore": 100 }
  ],
  "questions": [ ... ]
}
```

#### 单题 Schema 与 8 种题型规范

系统支持 `judge`（判断）、`single_choice`（单选）、`multi_choice`（多选）、`fill`（填空）、`term`（名词解释）、`short`（简答/作图/实验设计）、`calc`（计算/论述）、`proof`（证明/推导）八类题型：

- **通用必填字段**：
  - `no`: 整数，**必须严格按数组顺序从 `1` 连续递增到 `N`**（工坊加载会自动派生全局唯一题号 `<courseId>-<year>-<no>`），并与 `sections[].range` 首尾连续无缺口、无重叠地闭合
  - `type`: 上述 8 种类型之一（作图题与实验设计题统一使用 `short`，不得发明 `choice` / `draw` / `concept` 等非标准枚举值）
  - `score`: 单题分值；**全卷各题 `score` 之和及各 `sections[].totalScore` 之和均必须严格等于 `paper.totalScore`**（支持非 150 分制早期试卷如 100 分卷）
  - `title`: 简短清晰的考点标题
  - `stem`: 完整题干（包含全部已知物理量、边界条件、单位与各小问；数据表格统一使用 KaTeX `\begin{array}`，填空下划线统一用 8 个英文下划线 `________` 且置于 `$...$` 之外）
  - `answer`: 完整标准答案
  - `analysis`: 清晰完整的解析推导（含原理公式、代入数值计算、物理意义校验）
  - `chapter`: 对应 `chapters.json` 的章节号整数（新增 `exam` 年份包应优先复用目标科目的 `coreKps` 与既有 `method` 名称）
  - `figures` / `analysisFigures`: `[{"src": "figures/2024/q26_orig.webp", "caption": "图注说明"}]`（路径相对于资源包根目录，不能使用绝对路径或带盘符路径；无图填 `[]`）
- **题型专属字段**：
  - `judge`：`judgeAnswer` 必须为布尔值 `true` 或 `false`（`shortAnswer` 填 `"√"` / `"×"` 或 `"正确"` / `"错误"`；建议剔除题干末尾 `（　）`）
  - `single_choice` / `multi_choice`：`options` 必填（统一规范为 `[{"label":"A","text":"..."}, ...]`，原卷若为 `(1)(2)(3)(4)` 请转为 `A/B/C/D`），`choiceAnswer` 为 `"A"` / `"ACD"` 等，`judgeAnswer` 必须为 `null`（建议剔除题干末尾 `（　）`）
  - `fill` / `term` / `short` / `proof` / `calc`：`shortAnswer` 给出精炼核对答案，`judgeAnswer` 必须设为 `null`
  - 大题（`short` / `calc` / `proof` 且 `score >= 5`，含作图与实验设计题）**必须**配置 `rubric` 采分点数组：`[{"label": "采分点文字（可含行内公式）", "pts": 4}, ...]`；**若提供 `rubric`，`label` 不得为空，各 `pts` 之和必须严格等于该题 `score`**，且其中行内公式须通过 KaTeX 校验！
  - 可选增强字段：`note`（原卷印刷勘误、缺失题/缺失已知条件出处说明）、`pitfalls`（常见失分点与流传参考答案误区提示）、`kps`（知识点标签数组）、`method`（核心解题方法名）、`difficulty`（`1~5`）。

### 5. 内容与公式质量红线（AI / 人工整理必读）

1. **禁止原图 OCR 照抄出错、盲从错答与占位文本**：严禁留存「见原图」「OCR」「占位图」「待补充解析」「略」等偷懒内容；严禁无脑照抄扫描参考答案（旧卷常见页码错标、符号混淆或计算笔误），每个计算/推导题必须用 Python/SymPy 独立重算验算。遇原卷 OCR/印刷错漏，应修正 `stem` 并于 `note` 如实记录原卷印错处、于 `pitfalls` 提示常见错误口径；绝不凭空杜撰缺失题干，作图题原图 `qXX_orig` 需清除泄密答案曲线。
2. **公式、表格与符号严谨（KaTeX 九项铁律）**：
   - 行内公式用单 `$ ... $`（**中间严禁换行**），独立块级公式用 `$$ ... $$`（`formulas[].latex` 本身为纯 LaTeX 源码，**不要**外加 `$`）。
   - **题干或解析中的数值表格**请使用独立块级 KaTeX `\begin{array}{|c|c|...}\hline ... \end{array}`，勿用 Markdown 竖线表格语法（前端渲染器不解析 Markdown 表格）。
   - 变量字母用标准数学斜体（如 $v, h, Q$）；**单位与物理标注**用 `\mathrm{m/s}`（汉字进入公式必须用 `\text{...}` 包裹）。
   - **禁止空花括号上标**：遇到一阶/二阶导数或共轭水深时，用 `^{\prime}`、`^{\prime\prime}` 替代 `^{'}`、`^{''}`，度数用 `^{\circ}` 替代 `^{^{\circ}}`。
   - 长文字说明放在公式外部的中文段落中，不要写 `\text{很长一句中文}` 导致手机端溢出。
   - 不要出现未闭合 `$`、公式内未转义 `%`（须写 `\%`）或 `\left` 无匹配 `\right`；填空横线 `________` 必须置于 `$...$` 之外。
3. **配图推荐规格**：推荐无损/高质 WebP（分辨率建议 `900~1400px` 宽），若扫描原卷模糊/带噪点/有遮挡，务必用矢量绘图重绘白底工程简图，确保图内文字与题干符号完全一致；原图存 `figures/<year>/qXX_orig.webp`，解析辅助示意图（如测压管水头线、水面线分析、力学受力图、实验装置图）存 `figures/<year>/qXX_sol.webp`。

### 3. 解锁模式与美术合规要求

1. **解锁模式（`unlockMode`）**：
   - **`direct`（默认，推荐）**：安装并启用后，角色立即可在小鱼干补给站装备为首页/练习页看板娘。
   - **`gacha`**：放入小鱼干补给站卡池，用户通过刷题攒小鱼干抽取解锁（同一资源包内默认或用户切换均安全生效）。
2. **图片素材规格**：
   - 所有立绘与头像建议使用**透明背景 RGBA WebP**（立绘高度约 `700~1100px`，头像 `256×256px`），避免杂乱白底框破坏卡片视觉。
   - `spCards` 中的 `id` 不可占用内置保留 ID（`sp:dafeyu`、`sp:gemini`）。
3. **版权与非商业许可红线**：
   - `manifest.license` 与角色的 `credit` 必须如实标注画师署名、来源链接或 AI 生成说明，严禁包含未授权商用版权角色图或侵权二创内容。

## 五、一键检验、打包与导入指南

### 1. 使用统一 CLI 检验并打包（`scripts/pack_workshop.py`）

仓库内置标准打包脚本，可完成结构校验、配图存在性校验、总分/采分点守恒、禁用词扫描以及本地 Node KaTeX 公式语法全检：

```bash
# 校验并将目录打包为规范的 .jypack.zip
python scripts/pack_workshop.py --src ./my_pack --out ./dist/my_pack.jypack.zip

# 自动把包内 PNG/JPG 转为 WebP 并同步更新 JSON 引用（需 pip install pillow）
python scripts/pack_workshop.py --src ./my_pack --out ./dist/my_pack.jypack.zip --to-webp

# 演示/学习：从现有内置题库导出一整科或单年试卷为 .jypack.zip 范本
python scripts/pack_workshop.py --export-course hhu-814 --out ./hhu-814.jypack.zip
python scripts/pack_workshop.py --export-course hhu-814 --year 2026 --out ./hhu-2026.jypack.zip
```

打包完成后，终端会输出最终文件体积与 SHA-256 摘要，并提示是否满足 **15 MB** 站内直传阈值。

### 2. 三种导入与发布方式

1. **用户在浏览器直接导入**：
   - 打开系统顶部「**工坊**」（或 `#/workshop`）→ 点击「**从本地导入 .jypack.zip**」→ 系统在纯浏览器端完成 ZIP 解压与严格校验并写入 IndexedDB，秒级即可切换到对应专业课或装备新看板娘。
2. **站长上架到公共创意工坊目录**：
   - **≤ 15 MB 资源包**：站长可在工坊页打开「站长上架管理」→ 选择 `.jypack.zip` 直接分片直传上架。
   - **> 15 MB 超大资源包**：将 `.jypack.zip` 托管至 GitHub Releases 或公开 HTTPS 对象存储后，在管理面板填写 `https://` 直链登记即可（在线目录列表仍支持直接下载或本地导入）。
3. **Fork 源代码仓库作为内置题库发布**：
