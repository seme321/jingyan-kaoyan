# 手绘原题图片重绘与出图加速工作指南

> **适用场景**：将真题数据包中的手绘草图、灰底拍照图、涂抹扫描图、文字糊连原图批量重绘为「白底清晰工程示意图」，保持原图图意、已知条件与考题设问 100% 一致，兼具出图速度与整站风格统一。

---

## 一、质量定位：「轻量高保真」，拒绝过度内卷

1. **图意零偏差**：严格保留原图的所有物理拓扑、流体分层、边界倾角、流向箭头、断面标号及已知数字/字母符号。
2. **禁止脑补与答案剧透**：
   - 严禁凭“常见水力学题型记忆”擅自增删原图构件（如多画下游水池、漏画末端自由跌水、漏画中间支墩）。
   - 对于选择题、填空题、判断题的 `qXX_orig` 原题图，**不得补画题目未给出的求解辅助线、质心/压心位置，也不得“顺手纠正”原图故意画错的物理曲线**。例如 `2018 Q10`（错画水面线判断题）和 `2017 Q10`（错画水头线与负压区判断题），原图里的错误正是考题设问对象，必须原样重绘其“错态”。
3. **不追求 CAD 级毫米精度**：示意图重在线条利落、字母清晰、比例直观、深浅色模式下均无灰底噪点；参数（`DPI = 160`、WebP `quality = 85`）兼顾清晰度与体积（单图约 `10~25 KB`）。

## 二、四步高保真工作流（SOP）

### 第 1 步：拼图快筛（Contact Sheet 一眼扫完）
不要一张张打开几百张单图。用 Python + PIL 将 `web/public/data/<course>/index.json` 中就绪年份的 `figures` 每 `25` 张拼成一张网格总览图，人工或视觉模型 1 分钟即可精准框出所有需要重置的手绘/灰底/模糊图。

### 第 2 步：备份原图 + 原图四维审图（禁止凭印象动笔）
1. **先备份再覆盖**：在覆盖任何图片前，幂等将原 `web/public/data/<course>/figures/<year>/<stem>.webp` 与 `<已整理数据>/<year>/figures/<stem>.png` 备份至 `assets_src/handdrawn_backup/<course>/<year>/`（已存在备份则跳过，严禁二次覆盖备份）。
2. **逐张全分辨率读原图，动笔前强制确认 4 项不变量**：
   - **① 边界与构件清单**：是否有下游水池/水深还是自由出流、是否有末端跌水挑坎、是否有支墩/胸墙/铰点圆圈/土体折断符号 `~`？**逐个打钩，零增零漏**。
   - **② 物理高程与对齐不变量（代码硬约束）**：凡涉及淹没、齐平、包含关系的高度，禁止目测独立手填 `y` 坐标，必须用**共享变量/显式不等式**表达！例如：
     - 完全淹没闸门（如 `2017 Q09`）：必须显式满足 `y_gate_top < y_downstream_water < y_upstream_water`；
     - 隧洞顶与尾水齐平（如 `2017 Q15`）：必须共用同一个 `y_ceil` 变量画洞顶、闸门底边与下游水面。
   - **③ 曲线锚点、凹凸性与转折形态**：
     - 族曲线的起点/终点必须用数学函数**直接锚定到主线**（例如用 `y_cd(x)` 与 `y_ef(x)` 解析求交点），绝不凭肉眼凑坐标让支线悬空或穿过边界框；
     - 注意区分“先微降后上扬的勺形过渡（如尼古拉兹 `2017 Q11`）”与单调递增、区分“凸曲线”与“凹曲线”、区分“拐点处连续衔接”与“局部损失阶跃跌落”；
     - 禁止对直边界线使用 `np.clip()`（否则会在边界截出假水平尾段）。
   - **④ 题干与解析交叉核对**：模糊手写数字必须结合 `<year>.json` 的 `stem` 和 `analysis` 确认（如河海 `2018 Q28` 确认为 `$0.3\,\mathrm{m}$`、`2017 Q28` 原卷笔误 `$2=2\mathrm{m}$` 实为 `$z_3=2\mathrm{m}$`）；对错题判断类原图，确认“原图错在何处”以确保重绘精确保留该错点。

### 第 3 步：小批量调用 `scripts/fig_kit.py` + `--qa-dir` 出图
1. **小批量推进（每批 5～10 张，严禁盲写 30+ 个函数后再统一看图）**：每次只写 `5~10` 题，出图后立刻并排质检，避免系统性习惯偏差连续扩散。
2. 复用 [`scripts/fig_kit.py`](file:///c:/Users/6/Desktop/%E6%B0%B4%E5%8A%9B%E5%AD%A6/scripts/fig_kit.py) 标准化工程图元（`new_canvas`、`water_surface`、`ground_hatch`、`concrete_block`、`dim_arrow`、`section_cut`、`flow_arrow`、`angle_arc`、`piezometer`、`u_manometer`、`backup_and_save`）。
3. 重绘脚本统一注册于 `REGISTRY[(year, no)] = fn`，并提供标准 CLI：
   - `--year 2022`：只跑单年；
   - `--only 2018:10,2017:9`：质检发现瑕疵后秒级局部重绘；
   - `--workers 4`：通过 `ProcessPoolExecutor` 并行渲染；
   - `--qa-dir <目录>`：自动生成 `1600px` 宽高清无损 `.png`「原图 vs 重绘」并排对照表。

### 第 4 步：高清并排质检（反“美观幻觉”）+ 人工复核 + 缓存校验
1. **必须查看高清大图，禁止看低清缩略图糊弄过关**：使用升级后的 `build_qa_sheets`（`1600px` 宽、每页 3～4 组、无损 PNG）输出对照图，逐题按以下 **5 项反“美观幻觉”清单** 核查（不要只看重绘图“干不干净、好不好看”，要像找茬游戏一样跟左侧原图逐线比对）：
   1. **构件增漏核查**：原图每个箭头、支墩、铰点、跌水、折断线是否都在？有没有顺手多画水箱或辅助线？
   2. **高程与对齐核查**：门顶 vs 液面、洞顶 vs 尾水、左液位 vs 右液位、闸门与底板/顶板相对位置是否完全一致？
   3. **曲线形态与锚点核查**：起点/终点是否贴紧主线与边框？实线/虚线/点划线线型是否对应？阶跃跌落、凸凹方向是否一致？
   4. **题设意图与零剧透核查**：判断题的“错态”、选择题的待判区是否完整保留，未提前泄露答案？
   5. **标注与排版核查**：字母下标、单位、正负号、数字是否零错漏？是否有字母压线或彼此碰撞？
2. **高风险批次回传用户抽检**：整卷手绘图批量重置完成后，将并排对照图汇总后发给用户抽检，按反馈通过 `--only` 精准微调。
3. **缓存更新与双门禁校验**：替换线上 `web/public/data/` 图片后，必须升级 `web/public/sw.js` 的 `CACHE_NAME` 版本号，并运行：
   ```powershell
   node scripts/validate_course.mjs
   Set-Location web; npm run build
   ```

## 三、高频避坑清单（Matplotlib / Windows / 工程绘图）

| 问题类型 | 坑点表现 | 标准解法 |
| :--- | :--- | :--- |
| **`mathtext` 中文报错** | `$...$` 内写入 `\text{油}`、`$\rho_{\text{水}}$` 触发解析失败或乱码 | **中文一律放在 `$...$` 外**，用普通字符串拼接，如 `"油 " + r"$\rho_1$"` |
| **圆/半圆被压扁** | 未设等比例坐标轴时圆柱面变成椭圆 | 几何图统一使用 `new_canvas(..., equal=True)` |
| **多进程 Windows 崩溃** | 缺少主入口保护或传闭包函数 | 任务函数必须是模块顶层可 pickle 函数，且并行逻辑置于 `if __name__ == "__main__":` 内 |
| **原图文件名不匹配** | 生成文件名改变导致 JSON 引用断裂 | 严格沿用原 `qXX_orig.webp` / `qXX_orig.png` 命名原地替换，无需改 JSON |
| **重复运行覆盖原图备份** | 第二次运行把第一次重绘图当成“原图”覆写进备份目录 | `backup_and_save` 内先检查备份文件是否存在，已存在则跳过备份 |
| **独立手写 y 坐标失配** | 闸门顶错画到液面上方、洞顶与尾水未齐平 | 用**共享常量/不等式**联动计算（如 `y_gate_top = y_r_low - 0.65`），禁止写无关联魔法数字 |
| **`np.clip` 裁歪界线** | 对斜虚线用 `np.clip` 导致末端出现假水平拖尾 | 按框边界坐标精确求交点后直接画直线或样条（`ax.plot([ex, fx], [ey, fy])`） |
| **低分辨率 QA 图漏检** | `560×265` 有损 JPG 缩略图看不清虚实线、锚点缝隙和小铰点 | `fig_kit.build_qa_sheets` 固定输出 `1600px` 宽、每页 `4` 组无损 `.png` |

## 四、真实翻车复盘案例库（河海 2017 / 2018 批次实录）

在早期一次性批量重绘 35 幅手绘原图时，曾因“先写完所有脚本再扫低清拼图 + 按主观印象脑补模板”导致以下 **5 道题发生明显失真**（均已于后续专项核查中修正）。新批次制作与质检时**务必引以为戒**：

| 题号 | 此前重绘错法 | 制作时真实根因 | QA 阶段为何漏检 | 对应本规范铁律 |
| :--- | :--- | :--- | :--- | :--- |
| **2018 Q10** | 漏画右侧平坡末端**自由跌水挑坎**；`M1` 画成直线、`M2` 曲线在 `N2` 处断开；`N2` 标签压到竖虚线 | 未逐项核查原图右端细节；用简化线性插值替代了原题 `M1->M2->H2` 连续过渡曲线 | 只核对了三段坡度符号与文字标注，未沿整条水面线从左到右逐段追线 | 二·2 ① 构件清单逐个打钩 + ②·3 曲线连续性与形态比对 |
| **2017 Q09** | 粗黑闸门 `AB` 画得过长，顶端伸出了右下游水面之上；左右 `1 m` 改成了夹在双线间的双向箭头 | 把闸门错当作普通“半淹没平板闸门”模板来画，没看清原图考的是“**门顶铰点完全淹没**、上部为细固定斜墙” | 只看图面整洁、`(a)` 与 `1 m` 齐全，忽略了 `y_gate_top` 与下游水线的相对高低 | 二·2 ② 共享常量高程不变量 + 一·2 严禁套经验模板脑补 |
| **2017 Q10** | 在管道右侧**凭空多画了下游水箱与 `v=0`**；把两折弯处的局部损失阶跃画成了平滑连续直线、缺两个桥墩及 `d, v` 标注 | 套用了“水箱→管道→水箱”惯性模板；误以为原图阶跃只是手抖，擅自顺手“拉直”，违背了判断题原题特征 | 被重绘图漂亮的阴影土坡和虚线“美观幻觉”迷惑，没对比右侧是否存在下游水位 | 一·2 严禁大脑擅自“纠错”与脑补构件 + 二·4 五项反美观幻觉核查 |
| **2017 Q11** | `ef` 虚线因 `np.clip` 底部出现假水平尾段且未交于右下边框 `f`；5 条粗糙度曲线未锚定到光滑管 `cd` 线，且用递增指数公式画反了尼古拉兹标志性的“**先下凹后上扬**”勺形曲线；字母 `c/d` 压线 | 随手用 `exp()` 凑拟合式而非从原图锚点出发做二次贝塞尔；硬塞 `np.clip` 掩盖越界 | 缩略图分辨率太小，远处看“像是那么回事（几条曲线带横线）”，没有放大验证每条曲线起止点与凹凸方向 | 二·2 ③ 锚点解析函数绑定、禁 `np.clip` + 放大看无损 QA 图 |
| **2017 Q15** | 隧洞顶与右侧尾水一高一低未齐平、闸门底部反插进隧洞内部、土体拱顶漏画中部工程折断符号 `~`、进口喇叭口偏方硬 | `y_ceil`、`y_down_water`、`gate_y0` 各自手填了独立坐标，未盯住“尾水与洞顶齐平、闸门坐在顶缘上方”的构造细节 | 图元本身（`A/B`、`i=0`、箭头、闸门）元素全齐，肉眼一扫不易察觉这 `0.3` 单位的高程错位 | 二·2 ② 共享高程变量强绑定 + 二·4 逐构件精核 |

> **一句话复盘**：手绘重绘出事故，**80% 不是绘图技术问题，而是“脑补模板 + 公式硬凑 + 低清缩略图只看美不看像”的态度与流程漏洞**。严格执行「动笔前 4 项不变量 + 5~10 题一小批 + `1600px` 无损对照 + 反美观幻觉 5 项清单」，即可在保持极速出图的同时实现接近 100% 的首次准确率。
